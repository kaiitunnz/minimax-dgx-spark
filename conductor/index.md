## Project Summary

**minimax-inference** is a local inference server for running Minimax AI models on DGX Spark hardware, enabling Open Code integration for AI-powered automation and coding workflows.

### Key Outcomes

1. Minimax models running locally via Ollama endpoints for Open Code integration
2. Optimized inference performance on DGX Spark GPU
3. Reproducible, containerized setup for easy reset/reconfiguration
